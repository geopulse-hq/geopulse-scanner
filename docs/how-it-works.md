# How it works — detection protocol v1

The scanner and GeoPulse Cloud run the same protocol and the same reading rules; the files under `src/core/` are exported from GeoPulse unchanged (see “Keeping in sync”).

## 1. Asking

| | OpenAI | Perplexity |
|---|---|---|
| API | Responses API + `web_search` tool | Chat Completions |
| Model requested | `gpt-4o-mini` | `sonar` |
| Search | **required** (`tool_choice=required`); an answer without a completed search call is marked *search didn't run* | always retrieves on its own |
| Samples per question | 2 | 2 |

Each request contains only:

- the question, exactly as written in `scan.json`, and
- versioned neutral instructions (`sp-v2`): answer the actual need; for recommendation questions, name relevant candidates with their websites, favour no brand, don't invent or pad; cite sources.

Your brand, domain, competitors and earlier answers are **never** sent. The model each API reports it actually ran is stored with every answer.

Each call is retried at most once, and only for rate limits, server errors and timeouts.

## 2. Reading an answer

**Named:** your brand name or an alias appears in the text (not merely inside a URL).

**Recommended** (recommendation questions; competitors judged the same way) when one of these fires — the report shows which one and the sentence it fired on:

- `option_list_item` — a list item that starts with your name;
- `explicit_recommendation` — a recommending verb aimed at you (“consider X”, “X is a reliable option”);
- `provider_description` — you are the subject of an offering sentence (“X makes waterproof LED strips”).

Never counted: a generic “consider…” aimed at something else, or a mention near negative wording (shown as *negative* instead).

**Own site cited:** a citation, or a link written in the answer text, points to your domain or one of `ownedDomains`.

## 3. Numbers

- **Recommendation rate** = recommendation-question answers that present you as an option ÷ valid recommendation-question answers.
- **Citation rate** = knowledge-question answers citing your site ÷ valid knowledge-question answers.
- **Valid** = the call succeeded and, for OpenAI, the required search ran. Everything else is listed as a failure and left out of both numerator and denominator. A valid answer that doesn't mention you is a real zero.
- Each answer counts at most once for each outcome.

The two numbers are never blended into a single score.

## 4. Comparing scans

Two scans are comparable only when the questions, engines, models and instruction version are all the same. The report records all of them (`report.json → protocol`, and each answer's `model`).

## 5. Keeping in sync

`src/core/**` is generated by `scripts/export-scanner-core.mjs` in the GeoPulse repository. That script copies the detection modules, swaps their app-only dependencies (database, spend ledger) for small shims, and refuses to export if a file imports anything unexpected. Don't edit `src/core` by hand; change the rules upstream and re-export.
